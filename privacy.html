隐私政策

更新日期：2026 年 11 月 6 日

1. 适用范围

本政策说明「可学」（以下简称“本 App”）如何处理你的信息。本 App 是一款运行在你设备上的知识整理与学习工具：没有开发者运营的服务器，没有账号体系云端同步，也不需要注册任何在线账号即可使用。

使用本 App 即表示你已阅读并理解本政策；如果你不同意，请停止使用。

2. 我们收集什么

2.1 本 App 不收集你的个人信息用于分析、画像或广告：没有统计 SDK，没有广告 SDK，没有崩溃上报，也没有把任何数据回传开发者。

2.2 你在本机创建的账户名、密码（若设置）、学习计划、知识点、学习记录与设置，全部保存在你的设备本地（应用私有目录下的数据库）。

2.3 你填写的模型服务 API Key 保存在本机应用私有目录中，用于向你选择的模型服务发起请求。

3. 你输入的内容会发到哪里

3.1 当你在本 App 里提问、贴入材料、生成知识点或计划时，这些内容会连同你的 API Key 一起，发送给你所配置的模型服务提供方，由它处理后返回结果。这是本 App 唯一会把内容发出设备的行为，且由你的操作主动触发。

3.2 默认的模型服务提供方是 DeepSeek（杭州深度求索人工智能有限公司），你也可以在账户设置里填写其他兼容的服务地址；此时内容发给该地址对应的提供方。这些提供方如何处理你的内容，受其自身的服务条款与隐私政策约束，本 App 无法控制。

3.3 本 App 不在开发者控制的服务器上中转、留存或备份上述内容。除模型服务提供方外，本 App 不会把你的内容提供给任何第三方。

3.4 如果你使用联网搜索功能，查询词会发送给相应的搜索服务方；搜索结果的来源链接由第三方提供。

4. 保存期限与删除

4.1 本地数据保存多久，由你决定：删除账户会删除该账户对应的本地数据库；卸载 App 会清除应用私有目录下的全部数据。

4.2 系统的备份、云同步或你自行导出的文件可能保留副本，这部分需要你另行删除。

4.3 已发送给模型服务提供方的请求内容，其保存与删除由该提供方按其政策处理，本 App 无法代为删除。

5. 权限与设备信息

5.1 本 App 不读取通讯录、短信、相册、位置、麦克风与摄像头。

5.2 唯一涉及网络的用途是：向你所配置的模型服务地址发起 HTTPS 请求，以及在你主动点击时打开外部浏览器链接。

5.3 本 App 不申请设备标识符（IMEI、OAID 等）用于追踪。

6. 未成年人

6.1 未成年人应在监护人指导下使用本 App；API Key 的申请、费用与模型服务条款由监护人了解并同意。

6.2 建议不要输入身份证号、联系方式、住址、未公开试题、他人隐私或商业秘密等敏感信息。

7. 政策更新与联系方式

7.1 本政策可能随功能变化更新，更新后在本页展示最新版本并注明日期。

7.2 如对本政策有疑问，可通过应用市场详情页提供的开发者联系方式与我们联系。

免责声明

更新日期：2026 年 11 月 6 日

1. App 的定位

本 App 是一款本地学习辅助工具，功能包括：记录学习目标、计划和进度；接收你输入的学习材料、知识点或整理请求；通过你自行填写并保存在本机的 API Key，将请求发送给你配置的模型服务提供方；展示模型返回的结果；在本机保存学习计划、知识点、学习记录和设置。

本 App 不开发、不训练、不运营、不控制任何大模型，也不参与模型服务的定价、计费或结算。

2. API Key 与费用

2.1 你通过本 App 发起的每一次模型调用，均使用你本人申请并填写的 API Key，由你与模型服务提供方直接结算。本 App 不代收、不代付、不转售额度。

2.2 API Key 保存在你的本机环境中。发起请求时，Key 会作为身份凭证发送给你配置的模型服务地址，仅用于完成你主动发起的请求。

2.3 你应妥善保管 API Key。因设备丢失、转借他人、恶意软件、网络劫持或保管不当导致的未授权调用、超额扣费或账户损失，由你自行承担。

2.4 如果你填写了非默认的服务地址，请确认该地址可信，并自行了解其服务条款和隐私政策。

3. 生成内容

3.1 内容由大模型生成，可能有误，请自行核实。生成式人工智能的输出具有概率性，可能产生错误、过时、不完整或“幻觉”内容。本 App 不对模型返回内容的准确性、完整性或可靠性作出保证。
